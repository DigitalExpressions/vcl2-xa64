# ARM64 future investigations and plans

Place documents here for future ARM64 investigations, implementation plans,
optimization ideas and follow-up work, including Direct Neon and sse2neon
compatibility topics.

Use descriptive filenames and record the question or goal, proposed scope,
relevant source revision and evidence, and how the outcome could be validated.
Update each document's status as the investigation progresses.

Refer to the [ARM64 validation records](../../validation/arm64/README.md) and
[native validation workflow](../../validation/native-workflow.md) when planning
validation work.
