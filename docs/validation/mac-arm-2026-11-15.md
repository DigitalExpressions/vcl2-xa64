four timed out**, with no skips. All four timeouts were in Direct Neon 256

| `configuration` | Timeout, 1046.22 seconds elapsed | Passed, 29.01 seconds |

macOS power logs recorded a 941-second idle sleep from 19:12:38 to 19:28:19
CET, overlapping the three numerical timeouts, and a 1037-second maintenance
sleep from 19:31:19 to 19:48:36 CET, overlapping configuration. The deadlines
remained 60 seconds; suspended host execution accounts for the unusually long
elapsed timeout reports. A later maintenance sleep also delayed the next build.

An initial process-scoped `caffeinate -i` assertion prevented idle sleep but
did not prevent maintenance sleep. A temporary `caffeinate -is` assertion on
AC was then enabled, and both system-sleep and idle-sleep assertions were
verified. No permanent power setting changed; the temporary assertions were
released when validation finished.

After the original full runner exited, the entire affected Release profile
was rebuilt in a new directory and all **890/890 cases passed**, including all
four previously timed-out cases. The replay imported the unchanged published
runner's preflight, testbench checks, controls, profile implementation, matrix
entry and evidence packager. It repeated the native, UBSan and guard-page
controls and ran the example successfully. It did not filter the case list.

Including this replay, there were **8,926 case executions: 8,922 passes and

  with executable hashes retained. The runtime-query consumer passed with
  ARM64 and Neon enabled and `instrset_detect=0`.
- UBSan means Undefined Behavior Sanitizer. Each Debug profile used
  `-fsanitize=undefined -fno-sanitize-recover=undefined`, frame pointers and
  `UBSAN_OPTIONS=halt_on_error=1:print_stacktrace=1`. The ordinary control
  passed; intentional signed overflow stopped with the expected diagnostic.
- The actual host page size was 16,384 bytes. The writable-page control
  passed; forbidden reads and writes at both boundaries produced SIGBUS.
  Partial-count loops, exact boundaries and canaries remained intact.
- All cases retained their 60-second deadlines. Configuration and all five
  independent numerical fixture checks ran in each profile.
- Numerical inputs, seeds, references and acceptance gates were unchanged.
  Regression flags retained `-ffp-contract=off` and selected
  `-frounding-math`; `-ffinite-math-only` remained confined to classification.
- The independent audit reconciled JUnit results, registration, compile
  flags, source hashes, native binary records and archive integrity with
  zero audit errors. HEAD, tree, local branches, remotes and checkout state
